# Stup
----------------------------------------------------------------------------------------------------------------------------------------
Modern and lightweight launcher for Roblox and Roblox Studio. Built with C# (WPF) for the graphical interface and Python for core logic.

## Features
- Custom UI for launching Roblox
- Custom UI for launching Roblox Studio

## Tech Stack
- Frontend: C# (WPF, .NET 8.0)
- Backend: Python 3
